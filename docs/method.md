# 方法与实验设计

## 任务定义

对每张布面图预测三个可共存标签：经向异常、纬向异常、面积异常。模型输出三个独立 logits，经 sigmoid 映射为各标签分数；阈值 0.5 用于本报告的固定阈值统计。“任意瑕疵”表示至少一个预测标签为正。当前结果中的置信分数是模型 sigmoid 分数，未做概率校准。

## 输入构造

输入先保持 RGB 与辅助图几何对齐，再使用相同的中心裁剪/随机裁剪和翻转参数，缩放到 608×512。RGB 使用 ImageNet 均值和标准差归一化；辅助通道按对应输入分支处理。

| 分支 | 输入 | 通道数 | 掩码处理 |
|---|---|---:|---|
| 原图 | RGB | 3 | 无 |
| A | RGB + 连续布面分数 | 4 | 保留分割模型的软分数 |
| B | RGB + 灰度掩码图 | 4 | 分数阈值 0.3，掩码外填黑，再转灰度 |
| C | RGB + RGB 掩码图 | 6 | 分数阈值 0.3，掩码外 RGB 填黑 |

辅助分数由外部 ONNX 分割模型 `effb0_allv3v3_512.onnx` 生成。缓存元数据记录的模型 SHA256 为 `ece42a14e5d995ad5e4a4fa3836b91af7a99d3dd0ede5ce77ad6a407e667d733`。训练集和验证集的分数缓存均为 512×512 float16；先将输入图缩放到 512×512、转 RGB、按 ImageNet 均值/标准差归一化，模型输出经 sigmoid 转为分数。原模型权重不在本仓库。

## 训练

- 主干：Torchvision MobileNetV3-Large，ImageNet 预训练初始化。
- 三标签 BCEWithLogitsLoss，按训练集类别正负比例设置 `pos_weight`；AdamW、初始学习率 0.001、weight decay 0.0001、余弦退火、AMP。
- batch 32，最多 35 epoch，seed 42；A/B/C 分别训练。最佳 checkpoint 按验证表现保存。
- 验证集用于选择 checkpoint；测试集仅用于最终比较，不应再用于调阈值或挑模型。

## 解释边界

这个实验是“输入通道拼接后端到端重新训练分类器”，不是冻结原图模型后只训练融合头。掩码只是额外输入，分类器仍可查看原图。实验结果没有证明哪种融合对其他产线、相机或布种普遍更好。

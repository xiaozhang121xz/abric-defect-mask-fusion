# 数据与划分

## 训练 / 验证

- 训练集：35,672 张；验证集：3,590 张。三组实验使用相同样本和标签。
- 数据集由单一产线的 cap320 采样数据整理得到，类别标签为经向异常、纬向异常、面积异常，允许多标签共存。为避免披露业务信息，仓库不记录产线、工厂或织机标识。
- 训练和验证分别由 `train.txt`、`val.txt` 固定清单定义。实验验证了清单哈希与预计算布面分数缓存的 manifest 元数据一致。
- 本地和公开仓库不包含图片、标签 JSON、清单或缓存。完整数据路径只在有权限的实验环境中配置。

## 独立测试

- 测试来源为同一条产线的近期独立数据；初始集合 19,972 张，删除与训练重叠 4 张、与验证重叠 1,571 张后，保留 18,397 张。
- holdout：瑕疵 1,282 张、正常 17,115 张。经向 11、纬向 815、面积异常 485 个正标签；标签可共存，因此类别正例数之和大于瑕疵图片数。
- 本测试适合比较当前产线内的相对表现，不代表跨产线泛化。尤其经向正例仅 11 张，不能据此可靠评估经向性能。
- 不公开原图名称、织机号、工厂明细或逐图错误样本，避免披露业务数据。

## 公开数据前检查

确认是否获得图片、标注、工厂信息和脚本的公开授权。当前仓库只放聚合计数和指标，不放原始样本、分割图、逐图预测、图像哈希或缓存数组。
